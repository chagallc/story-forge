> 快照日期 2026-11-04。扫描者：辉月姬。
> 方法：GitHub Search（API/搜索页）中英关键词多轮交叉扫描（humanize / anti-slop / 去AI味 / AI味 / burstiness / detectgpt 等 20+ 组），web 检索补漏，星数与更新时间均为当日快照；"更新"指最近 push。共收录 32 个项目。
> 归档原因：决策 0004 的依据材料。

三个总判断：

1. 英文生态以 "Claude Skill 化的规则库"为大头，中文生态的方法论密度更高、更讲究误杀防护
2. burstiness/perplexity 没有高星独立开源库，中文侧最强的量化体系来自一个 520 万字的实证研究项目
3. 小说专用的去 AI 味方案在中文侧已经自成体系（网文产业链）

## 最值得整合进小说引擎 Top 5

1. **lieflat-less-ai-tone**：唯一经过严格实证的中文 AI 腔度量体系。90 项脚本指标可做成"章节 AI 味 lint"，9 项语义指标可变成评审 agent 的打分 rubric；模型指纹感知是独门能力。
2. **zenstory-ai/oh-story-claudecode**：最成熟的网文全流程实现，去 AI 味已工程化为确定性门禁脚本，直接拆出来当引擎成稿门禁；MIT 协议。
3. **RTY798/agent-novel**："事实门禁 vs 风格观察"二分法正是多智能体长篇引擎最需要的架构原则。全场价值密度/星数比最高。
4. **shuorenhua（说人话）**：Tier 分级 + 保护机制正面解决误杀风险；改写 agent 的规则层照抄即可。
5. **antislop-sampler（+ auto-antislop 识别管线）**：唯一生成侧拦截路线。API 模型退化为"生成→slop 检测→重采"循环。

荣誉提名：De-AI-Prompt-Enhancer 双模式（多角色"每角色一份声口 DNA"）配合 nuwa-skill 蒸馏方法论；Binoculars 一行公式加进质量面板。

整合架构一句话：**三层防线 + 一个声口层**——生成侧拦截 → 章节级指标评审（gate 事实、风格只观察）→ 后处理润色（Tier 规则）→ 全书角色声口。
