# 故事图谱与记忆系统调研报告（朱雀 · K3.1-Pro）

> 调研日期：2026-11-05 快照 · 依据：story-forge 现有数据契约（bible/state/ledger/card）+ 月华的「图形/神经树后台地图」需求
> 核心边界：图谱不做第二正史，只做 `story-state.json + ledger + card.json` 的派生投影

## 路线结论

**以已提交的 canon.md 为输入，生成不可变的章级 ChapterFact；用带时间、视角和证据的增量图谱承载人物与剧情变化；在弧级生成可追溯的「反思记忆」；图谱和网页地图都是现有 story-state.json / ledger / card.json 的派生视图。**

不建议第一版引入 Neo4j、完整 GraphRAG 或自主改写记忆的 Agent。story-forge 已有正史状态和伏笔暗账，真正缺的是：
1. 章级事件记录（这章具体发生了什么、谁参与、改变了什么）
2. 历史而非覆盖（关系、知识、动机变化不能只保留最新值）
3. 弧级整理（人物弧线、关系弧线、未闭合问题）
4. 多视图可视化（剧情因果图、人物关系图、角色时间线、知识/伏笔图，不塞进一张力导向大图）

## 二、设计输入

### 1. 图谱数据模型：事件溯源 + 版本化事实

**事件记录「发生了什么」，版本化边记录「从此什么成立」，当前状态由截至某章的事件重放得到。**

节点类型：Character（静态栈留 bible）/ Chapter-Scene-Event / Location-Item-Faction / Fact（可被知道/误解/不知道的秘密）/ Hook（对应 ledger）/ ArcReflection（派生记忆，不自动成正史）

边类型：结构（CONTAINS/NEXT_IN_STORY）、参与（PARTICIPATES_IN + role=actor|experiencer|witness|source）、空间物品（OCCURS_AT/LOCATED_AT/TRANSFERS_ITEM）、因果（CAUSES/ENABLES/BLOCKS）、关系（RELATES_TO + type/stance/valid_from/valid_to/caused_by，**双向不对称**）、知识（KNOWS/BELIEVES_FALSE/UNAWARE_OF + LEARNED_FROM）、伏笔（PLANTS/ADVANCES/REVEALS/RESOLVES）、人物发展（PRESSURES(motive,cost)/SHIFTS_MOTIVE）、章节合约（FULFILLS_PROMISE/RECORDS_CONSEQUENCE）

公共字段：chapter_id/event_id/canon_revision/evidence_span/extractor_model/prompt_version/confidence/status(accepted|suspect|rejected)

三种时间：①故事内时间 ②叙事顺序（读者第几章读到）③提交版本。事件 modality=actual|hypothetical|planned|rumored（防设想写成事实）。

### 2. 触发与管线

**触发点挂 canon commit，不挂 draft 写完。**

```
canon.md + card.json + 上章摘要 + 实体词典 + 活跃 hooks
  → 生成/补全 ChapterFact（严格 JSON）
  → 确定性校验（Schema/实体 ID/证据 span/状态操作白名单）
  → 与 STATE_DELTA 对照；冲突进人工确认
  → 现有 reducer 原子提交 canon + story-state + ledger
  → 保存已接受的不可变 ChapterFact
  → 增量追加图节点/版本化边，重建派生视图与检索索引
```

图谱不能直接修改 story-state.json——发现的遗漏只能让 commit 失败或生成待审补丁。

模型分工（用现有异构阵容，不加 Provider）：中文初抽取 qwen3.8-flash（与 writer GLM 异构）；弧级整理 GLM/K3.1（归纳人物变化和因果）；英文 LLM 语义事实 + 需要时 BookNLP 辅助共指。第二遍查漏不每章跑——弧末/重大反转章/校验失败章优先。

增量 vs 全量：每章增量抽取，绝不每章全书重交 LLM；弧级整理每 3-5 章/弧末/重要性阈值触发；全量重建只重放已接受数据（Schema 升级时无需重调 LLM）；旧 canon 修订→该章重抽+下游标 stale。

弧级整理产物：本弧关键因果链/每人动机排序变化及证据/关系变化链/新知道-仍误解-仍不知道的关键事实/活跃-已回收-逾期伏笔/未解决矛盾与下一弧承接问题。**反思只引用已有事件，不得发明新事实**；推测单独标 hypothesis 不进正史投影。

### 3. 可视化：本地网页为主，Obsidian 为导出

workbench 增加本地 map 视图，数据 JSONL/SQLite，前端 Cytoscape.js。第一版不引 Neo4j。

四个联动视图（不只一张神经树）：
1. 剧情因果图（Chapter/Scene/Event 节点 + 计划/扰动/选择/后果/因果）
2. 人物关系图（默认当前章有效关系；双击展开局部网络；边看变化历史与证据）
3. 角色泳道时间线（位置/伤势/物品/动机压力/知识获得；故事时间与阅读顺序切换）
4. 知识与伏笔图（作者/某角色/读者三视角切换）

关键交互：章节滑块与上一章 diff、点击节点跳 canon 证据、suspect/冲突/人工修正不同线型、默认聚焦当前章子图（防长篇毛线球）、**作者视图与读者视图物理区分（防地图泄底）**。
