## 二、月华批评引出的设计变更：故事引擎层

### 病根（人工盲评 + Neil Gaiman"what happens next"标准）

试点三本的共同缺陷：大纲是**名词**（事件罗列）不是**动词**（计划交易）；钩子是**物件**不是**问题**；主角没有**计划栈**，底牌回收以"答案公布"而非"计划崩塌"的方式到达。读者的疲劳 = 没有目标 jeopardy 的信息流。

### 三层设计（自上而下，上层约束下层）

```
第一层 弧线（宏观骨架）  模板库按题材选取 → 锚点（召唤/跨门槛/中点磨难/黑暗时刻/高潮/归宿）
第二层 包络（节奏管理）  锚点间布中反复；振幅分级；呼吸拍强制；开环预算；闭环调律
第三层 细胞（引擎循环）  每章四元组：计划 → 颠覆 → 危机 → 临场应变；章末断章钩子
```

- **引擎参考**：Swain 场景/续场循环（目标-冲突-灾难 / 反应-困境-决定）
- **节奏参考**：网文实战公式（张 3 弛 1；大高潮前 4-5 章蓄力、后 2 章恢复）；习惯化与对比效应（振幅必须分级，均匀强度 = 疲劳）
- **骨架模板库**：英雄之旅（Vogler 十二阶段）、起承转合（四段式，非对抗驱动）、悬疑假设弧、爽文蓄放弧；**长篇分形**：每卷一条小弧嵌全书大弧（与 ainovel-cli 卷弧滚动规划同构）
- **闭环调律**：读者探针逐章回传欲望分与"最想知道的问题"，疲劳信号（峰值后深回落/曲线平坦化）只调整包络层，锚点不动
- **明确否决**：随机 timer（破坏蓄放因果）；每章全功率循环（习惯化 → 反转贬值）

### 与暗账的绑定规则

底牌回收章 = 高振幅章。回收以"计划摧毁"的形式到达（凶器是"停药"，不是"答案揭晓"）。大振幅位置（中点/高潮）优先绑定最深底牌。

## 三、结局盲探针与影子暗账（月华设计，2026-10-12 补入）

月华盲判时指出：读到陆则明部分即可预判自蘋是凶手，建议在结局前加一道盲眼判定，视可预测性决定是否注入额外反转。采纳为正式机制：

### 3.1 结局盲探针（Pre-Climax Blind Probe）

- **时机**：高潮章开写前（如 12 章本的第 10 章末）
- **探针**：全新异构盲读者实例，读到第 N-1 章，直接三问：①预测凶手/手法/动机，给置信度 ②“还有什么结局会让你惊讶但觉得公平？” ③哪些已读细节支持你的预测？
- **判定规则**：
  - 预测正确且置信度 ≥ 8 → 结局可预测 → 评估影子层是否具备引燃条件
  - 预测错误或置信度低 → 维持原结局（反转不是必需品，探针让它是条件品）

### 3.2 影子暗账（Dormant Shadow Ledger）

每部作品自设定阶段就带一层低显著性钩子的“影子真相”（如：沈樵早已发现自己病入膏肓/早已发现换药，选择停药赴死——把谋杀重释为“知情者的自我了断”）。两种反转型：

- **重释型**：不增加新事实，仅翻转已有细节的含义（公平性最高，无需额外埋设）
- **深潜型**：真凶另有其人（如小满），需影子层从第 1 章起携带轻量钩子

### 3.3 公平性铁律（Fair-Play Constraint）

反转必须可回溯：要么已有钩子支撑，要么已有细节可重释。**零前置支持的反转 = 作弊**，读者感到被欺骗而非被惊艳。影子层钩子植入时受“低显著性”约束（复用渲染模糊度机制），确保不干扰主线阅读。

### 3.4 与闭环调律的关系

闭环调律管中观节奏（峰谷挪移），盲探针管宏观结局（要不要翻终局）。两者都只读读者信号、不动锚点——但盲探针是唯一有权改变“真相本身”的机制，且只能在高潮前行使一次。
