# 决策记录 0003 · 动机压力层（人物动机弱的结构性修复）

- 日期：2026-11-04
- 提案：月华（反馈"人物动机太弱，推动人物行动的原因太薄弱"）
- 设计与实现：Hanako
- 状态：已采纳，随 exp003 生效

## 1. 诊断：动机弱不是 prompt 问题，是数据结构问题

复盘 exp002 丁本与全部产物，人物行动力薄弱的根因有四个，全部在结构层：

1. **人物卡单薄**：`spec.characters` 每人只有一行 card。写作 agent 眼中的"人"是一张名牌，不是有欲望的人。行动没有欲望源头，只能从情节需要反推。
2. **细胞四元组是纯情节力学**：plan→disruption→crisis→improvisation 全部围绕"计划"运转，但**计划为什么必须是"他"的计划**没有任何约束。人物沦为计划的执行器，谁来做都一样。
3. **动机出口被单向堵死**：WRITER_SYSTEM 规定"禁止上帝视角解释人物动机"（show-don't-tell，本意正确），但输入端没有供应动机原料——只堵不供，等于把动机从故事里饿死。
4. **测量盲区**：reader 只测欲望分与猜测，不测"行动是否可信"。动机弱在数据上不可见，反馈回路从未捕获过它。

## 2. 设计：动机压力层（Motive Pressure Layer）

### 2.1 人物卡 → 动机栈

每角色七字段，是人物行动的总账：

| 字段 | 含义 | 功能 |
|---|---|---|
| `want` | 表层欲望（角色自己知道） | 直接驱动行动 |
| `need` | 深层需求（角色自己没意识到） | 主题层，结局兑现 |
| `wound` | 旧伤 | 解释他为什么这样行事（说服力的根） |
| `value` | 底线 | 可让他翻脸/越线的东西 |
| `fear` | 恐惧 | 压力测试点，XL 章打这里 |
| `contradiction` | 内在矛盾 | want 与 need/value 冲突的具体形式 |
| `voice` | 说话习惯/标志物（可选） | 人物辨识度 |

### 2.2 细胞增加 pressure 字段

每章 1-2 条动机压力，必须与本章 plan/disruption **咬合**（同一个力既推情节又压动机，不另起炉灶）：

```json
"pressure": [
  {"char": "何一鸣", "motive": "want|need|wound|value|fear",
   "force": "什么力在压这个动机（与本章计划/颠覆同源）",
   "cost": "行动代价：他为此要放弃/冒失/暴露什么"}
]
```

约束：XL 章至少一条打在 `fear` 或 `value` 上；代价必须可见（行动要花钱、冒风险、留把柄，三选一起步）。

### 2.3 写作侧：动机链四问

每个重要人物行动必须能无声地回答四问（以场景与选择呈现，不旁白）：

1. **她此刻想要什么**（want 的场景化）
2. **什么拦住了**（force）
3. **为什么是现在**（时机压力）
4. **为什么是她**（换一个人不会这么做：wound/value 差异化）

原"禁止上帝视角解释动机"纪律保留——现在输入端有原料，纪律不再导致饥饿。

### 2.4 B 拍绑定动机消化

呼吸拍（sequel）的"反应-困境-决定"三步必须写到受压角色的内心消化，**决定必须体现其对动机排序的更新**（B 拍的产出物是重新排序，不是事件）。

### 2.5 测量升级

reader 新增字段：

```json
"motive_check": [
  {"char": "谁", "action": "哪个行动", "believable": 1-10, "why": "一句话"}
]
```

metrics 聚合为 motive_curve（逐章人物行动可信度均值）。验收线：均值 ≥7 且无单章 ≤5；月华盲读追加一问：**"有没有哪个行动让你出戏（他不会这么做）？"**

## 3. 与现有机制的边界

- 防火墙管的是**未来信息**，不管"他人内心"——作者全知人物动机栈是正当的，动机栈对 E 臂 writer 全量可见
- 影子暗账（决策 0002）物理拆分升级：`shadows` 独立于 `ledger`，任何写作投影不可见，仅盲探针评估通过后注入高潮章引擎指令
- 闭环调律仍只动包络；盲探针仍是唯一可改真相的机制

## 4. 验收（exp003）

1. motive_curve 均值 ≥7，无单章 ≤5
2. 三连反应验收法照旧 + 第四问：行动可信吗？
3. 对照：E2（动机压力层）vs E1（纯情节引擎），同题材同暗账，唯一变量 = 动机层
