## 1. 扫描结论（摘要）

英文生态以 Claude Skill 化规则库为大头（blader/humanizer 64.5k 星是事实标准）；中文生态方法论密度更高——lieflat-less-ai-tone 用 520 万字人机对照实证筛出 9 条统计显著的中文 AI 腔信号（「不是A而是B」对仗 δ+0.88 为最强），并发现模型指纹（GPT 与 Opus 的破折号倾向方向相反）。小说专用方案在中文网文侧已自成体系（oh-story-claudecode 8.3k 星）。

## 2. 三层防线设计

### 第一层 · 生成侧（已实现）

写作 system prompt 注入文风守门简版（六条，≤200字）：禁对仗句式、禁模板腔、允许自然重复、句长波动、少破折号冒号腔、段落不碎。规则源文件 `docs/style-guard.md`，随 agents.py 的 WRITER_SYSTEM 常量同步。

### 第二层 · 度量侧（已实现）

`src/harness/style_lint.py`：确定性、零 token、**只观察不退稿**（agent-novel 二分法：事实与指令错误才拦截，风格只出报告）。8 项检查（对仗句式/模板句/句长CV/冒号总结腔/破折号密度/欧化腔/超短段占比/平均段长），已接入 analyze.py 输出 `style_lint` 节。

### 第三层 · 后处理润色（待议）

shuorenhua（说人话）的 Tier 分级 + 保护机制（角色口癖/专有名词/方言免死金牌）与 qu-ai-wei 的门检式改写管线，作为独立润色 agent 的候选方案。**暂缓理由**：生成侧与度量侧的闭环尚未验证，先看 E2 实验数据再决定是否需要润色层——每章多一次 LLM 调用的成本不小，且可能磨掉引擎层刻意保留的粗粝质感。

## 3. 与动机压力层的关系

AI 腔与动机弱同源：都是"没有真实欲望驱动的文字在空转"。动机链四问让行动有根，风格守门让句子有呼吸；二者在 E2 实验中同时开启，验收指标分开（motive_curve vs style_lint）。
