## 2. 开场契约（Opening Contract，spec 新增字段）

前 4000 字（≈ 前两章）必须完成的四件事，写作 agent 逐条对账：

1. **want 显性化**：POV 人物的表层欲望在前 1500 字内通过场景（非旁白）呈现
2. **扰动入场**：打破日常的 disturbance 在第 1 章第 1 场出现
3. **对话密度 ≥40%**：前两章对话行占比不得低于全书均值，核心冲突至少有一半在对话中揭示
4. **零设定倾倒**：世界观信息全部通过冲突、对话、动作带出，出现任何 info-dump 段落即违规

## 3. 对话驱动指标（metrics 新增）

- `dialogue_ratio`：每章对话行（含引号的行）占全章行数比例
- 开场契约期（前两章）≥40%，全书均值参考 30%
- `dialogue_seq`：连续三章对话占比递减 = 节奏塌陷预警
- 配合既有 style_lint：描述段落连续超过 4 段无对话 = 拖沓预警（正是 DS 稿的病灶）

## 4. 声口系统（动机栈 voice 字段升级）

```json
"voice": {
  "catchphrases": ["数数：四十一级台阶"],     // 口头禅/标志行为
  "speech_habits": ["短句", "用价格回答问题"], // 句式习惯
  "forbidden": ["不会说长句", "不用感叹号"],   // 此人物绝不会有的说话方式
  "sample_line": "行。"
}
```

讨论工作台设定，写作 prompt 注入，对话行由声口卡约束——这是"对话抓住读者"的人物层基础。

## 5. 工作台对接

写作工作台（另见 workbench 设计）中：开场契约为建书必填项；人物声口卡为人物卡必填项；每章讨论时 AI 编剧必须先报告本章的对话密度预算与 disturbance 位置。
