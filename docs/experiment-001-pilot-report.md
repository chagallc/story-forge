## 三、四个发现

**1. 惊讶度保存：C ≫ B > A，单调。** 防火墙在读者体验层面买到了它想买的东西：C 的读者在回收章前只持有类型级猜测，核心反转（停药杀人）到第 9-10 章仍然有效；A 的读者第一轮就拿到两张底牌。

**2. 泄漏有两种形态，全知臂两种都犯。**
- 明文泄漏（金丝雀可测）：A 把"七弦"写了三遍，读者第一轮直接引用原文锁定换药——硬泄漏不只是统计数字，是实打实的剧透。
- 渲染精度泄漏（金丝雀测不到）：B 从未写过"蓝鬃"，但全知写作 agent 知道底牌是蓝印章，把钩子渲染成"深蓝色印章状物"，GLM 读者据此+深蓝绒布拼出 F1。**信息通过"画得多像"流出，只有异构裁判能抓到。**

**3. 故事漂移：看见暗账 ≠ 执行暗账。** A 把"七弦"从厂标改成了药名；B 把维生素写成淀粉、把安眠药线改成偷账线。全知臂的写作 agent 依自己的叙事审美改写了底牌。C 则反向漂移：自造了"十几年前旧案"支线（读者反而评价"细节埋得密"）。**暗账需要提交时校验（黑塔的语义指纹拦截器），且 C 的自造伏笔需要重新定性：既是漂移风险，也是墙内释放的创作自由。**

**4. 张力未塌，但有变薄迹象。** C 的欲望曲线与 A/B 持平（DS 读者口径），但章长最短（-21% 对比 A）。质的判断留给人工盲评。

## 四、方法学缺陷（诚实清单）

1. n=1/臂，LLM 随机性未估计——正式批次需 5 次重复
2. **每本只有一个盲读者：读者效应与版本效应混杂**（版本二的读者可能单纯更擅长猜谜）。正式批次需读者轮换（每本 ≥2 个不同实例）
3. DS 读者与写作同家族，其"软泄漏首中第 1 章"的口径偏悲观（类型先验放大）；惊讶度结论以 GLM 盲读者为准
4. 关键词软泄漏匹配偏松（"下药"等泛化词会误计）
5. C 章长显著偏短，字数本身可能影响线索密度与猜测难度
6. 三本的故事事实已漂移（见发现 3），"同一故事三臂对照"的严格性打折

## 五、结论倾向与下一步

方向性结论：**防火墙假设在试点中获得双维度支持**（硬泄漏 0 vs 5；惊讶度完整保留），张力未受损；指令纪律单独也有贡献（B 的泄漏介于 A、C 之间）。行为说同样成立：三本的 DS 读者都在第 1-3 章给出类型级正确方向，墙挡不住先验。

建议路径：
1. 月华人工盲评三本全文（匿名化交付），重点裁断"章长变薄是否伤害质感"与"自造支线的价值"
2. 正式批次：3 臂 × 5 次，GLM 读者轮换（每本 2 实例），DS 读者只作过程量
3. 数据齐后出决策记录 0002：防火墙去留 + 自造伏笔的处置原则
