# 评审任务书 · Story Forge

致各位参与评审的 AI：

这是一个处于立项阶段的项目，请你在阅读本任务书和相关代码后，**独立**输出一份评审意见。你们互相之间看不到彼此的意见，这是故意的——我们要的就是不互相污染的独立判断。

## 项目一句话

用多智能体架构解决 AI 长篇写作的"设定提前泄底"问题：让不同的 agent 分别掌管背景设定、人物性格、事件触发与叙事执行，并用**信息防火墙**控制每个 agent 能看见什么。

## 核心构想（需要被你挑战或验证的东西）

1. **病根判断**：单模型写长篇忍不住吐设定、提前暗示伏笔，根因是"所有信息在同一上下文里，没有隐私"，而不只是上下文长度不够
2. **四路分工**：设定管理 agent、人物性格 agent、事件触发 agent（正负向命运之手）、叙事写作 agent
3. **角色 sub agent**：角色在性格底板之上由独立 agent 驱动，持有私有认知状态（包括错误信念），对白由角色 agent 博弈产生，叙述者统一润色成文
4. **信息防火墙**：事件 agent 持"伏笔暗账"，写作 agent 只能查询"当前可埋的钩子"，看不到未来走向；角色 agent 互相不知道对方的秘密
5. **读者模拟器**：每章写完让一个只读正文的 agent 预测"读者此刻能猜到什么"，用来检测暗示是否过早
